# Contributors and Source Lineage

This repository contains more than one implementation of a travel-agency coursework project. Contributor information is documented only where the repository itself provides evidence; Git commit authorship is not treated as proof of academic contribution.

## Main Swing application

**Location:** `Travel Agency GUI/`

This is the recommended/current portfolio implementation in the repository. It is a Java Swing/AWT desktop application with user registration/login, administrator screens, domestic and international destination flows, predefined and custom package selection, local price calculation, and simulated payment interfaces.

The current Swing source files do **not** contain an explicit project-team or contribution table. For that reason, this repository does not assign or infer co-author percentages for the Swing implementation.

## Attribution policy

- Academic contribution is credited from explicit project/source evidence when available.
