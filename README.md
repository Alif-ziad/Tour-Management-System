# Travel Agency Management System

A Java Swing desktop application developed as an academic software project for travel-agency operations.

## What is in this repository

The source is under `Travel Agency GUI/` and includes Java classes for application startup, user/admin interfaces, package selection, payment flows, and supporting screens. The entry point is `Start.java`, which opens the `Welcome` interface.

## Run locally

Requirements: a JDK with `javac` and `java` available.

```bash
cd "Travel Agency GUI"
javac *.java
java Start
```

The repository currently also contains compiled `.class` files and local data files from development. For a cleaner production-style repository, generated class files should eventually be removed and recreated during the build.

## Tech

- Java
- Java Swing / AWT
- Desktop GUI and event handling
- File-based project data
